Projects

SipTrack

LIVE

A happy-hour discovery platform. It shows which bars near you have a deal on now, what it is and how long it lasts. I built and run all of it: the iOS app, the website, the database and the data pipeline that finds the deals.

iOS app SwiftUI and SwiftData. Map, deal list, venue pages, friends and chat.
Website Next.js on Cloudflare, plus Pages Functions for small APIs.
Backend Supabase Postgres with row-level security, RPCs, edge functions and numbered SQL migrations.
Venue data An LLM pipeline. Gemini, or a local open model through Ollama, turns each bar's own page into schema-constrained JSON deals. A rule-based validator drops any deal whose price, item or times it cannot find on that page.
Monitoring Sentry in the app. A Cloudflare cron worker checks live pages and APIs and sends Resend email alerts. A scheduled GitHub Actions job runs storage cleanup and a health check.
